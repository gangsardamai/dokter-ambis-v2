## Kebijakan izin yang diharapkan
- Mahasiswa/pengguna tautan: **reader/viewer**, tidak diberi kemampuan editor oleh tautan publik.
- Admin serta tentor yang perlu memperbarui materi: hak `writer` melalui akun yang ditunjuk **secara eksplisit**, dipertahankan setelah pengetatan izin umum.
- Folder induk dan setiap file sensitif harus diaudit dari sumber sebenarnya; perubahan izin folder dapat memengaruhi banyak subfolder dan akses rutin. Selalu bandingkan daftar kolaborator eksplisit dan uji akses peserta sebelum/sesudah.
- **Akses 'anyone:writer' bukan pengaturan yang aman untuk materi mahasiswa.** Ditemukan pada 13/14 folder utama. UMS Endokrin 2026 sudah `anyone:reader` dan tidak perlu diperluas.
- Koneksi Google Drive yang tersedia saat audit **tidak menyediakan aksi untuk mengubah izin publik folder yang sudah ada** (aksi share-file hanya menerima file dan tidak menyediakan permissions.update untuk `anyone`). **Jangan mengklaim izin sudah diperbaiki** sebelum izin nyata di Google Drive berubah.
- Untuk setiap folder dengan `anyone:writer`, status `needs_permission_hardening`. Hindari menambah cakupan pengeditan, mengubah owner, atau menurunkan izin kolaborator eksplisit secara massal. Migrasi otomatis yang belum punya audit izin ekuivalen harus diblokir dan diberi laporan audit saja.
- Prioritas pertama hardening: folder utama UNEJ Blok 8 dan dua subfolder pilot; kemudian 12 folder lain yang masih `anyone:writer`. Jangan mengubah file asli milik tentor secara sepihak jika izin akunnya tidak mendukung.
